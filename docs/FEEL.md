# ゲーム体験の調整（1.1）

## 方針

通常の攻撃命中は局所的な反応で伝え、操作と回避を止めない。ボムやスペル突破だけを大きな解放として扱う。演出のために当たり判定を拡大したり、カメラを常時揺らしたりしない。

桜井政博氏のチャンネルで扱われているヒットストップ、リスクとリターン、再挑戦のテンポ、視認性というテーマを、この弾幕STG向けに解釈した実装です。全動画の視聴・字幕確認に基づく監修ではありません。今回の環境ではYouTube本編と字幕を取得できなかったため、公開されている紹介・動画テーマを起点にしています。下記の数値は本作での調整値であり、桜井氏が推奨した数値ではありません。

## YAMLの `feel`

ルートに任意で追加できます。省略した項目は標準値です。既存のYAMLを変更しなくても、新しい手応えを利用できます。

```yaml
feel:
  shotInterval: 0.09
  hitFlash: 0.065
  bossStop: 0.12
  enemyTell: 0.4
  bombClear: 0.65
  pickupRadius: 80
  focusPickupRadius: 130
  autoCollectY: 180
  grazeStep: 25
  grazeBonus: 1500
```

|項目|意味|許容範囲|
|---|---|---|
|shotInterval|自機の射撃間隔（秒）|0.045〜0.3|
|hitFlash|命中時の局所的な発光（秒）|0〜0.15|
|bossStop|スペル突破時、弾消し後の停止（秒）|0〜0.25|
|enemyTell|雑魚が画面内に入ってから発射できるまで（秒）|0〜1.5|
|bombClear|ボム後の新規弾抑制（秒）|0〜2|
|pickupRadius|通常移動時の吸引距離（ゲーム内px）|18〜200|
|focusPickupRadius|低速時の吸引距離（ゲーム内px）|18〜240|
|autoCollectY|自機がこのY座標より上にいると全アイテムを吸引|0〜300|
|grazeStep|ボーナスを付与するグレイズ回数|1〜200の整数|
|grazeBonus|到達ごとの加点|0〜10,000|

座標は480×640の固定ゲーム座標です。見た目の解像度を変えても判定の大きさは変わりません。

## 変更しないもの

物語、7種類の弾幕、元のボス構成、120Hz固定ステップ、相対的なswept collision、YAMLの検証と安全な式評価を維持します。演出軽減では描画のみを減らし、弾数・スコア・乱数によるゲーム進行は変えません。

`R`によるボス再挑戦は、スペル開始時の進行・スコア・パワーを復元し、残機とボムを初期値に戻します。やり直しで得点を積み増すことはできません。練習／コンティニューの結果はハイスコアに保存しません。スコア体系が変わるため旧版のハイスコアと保存先を分けています。

## 検証

既存34件に、射撃段階、停止の限定、吸引、グレイズ、再挑戦、安全な設定値など15件の回帰テストを追加しています。

Playwrightでは、実際のWebGLコンテキスト、物語、命中、ボム、停止、再挑戦、YAML検証、モバイル相対ドラッグ、横はみ出しなど24項目を確認します。スクリーンショットと結果JSONはActionsの検証artifactに出力し、ソースツリーには置きません。実機iOS Safari、実機スピーカーでの音量バランス、主観的な操作感の良し悪しは自動テストだけでは保証できません。
