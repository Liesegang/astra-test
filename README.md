# 月影異聞 — Moonlit Archive

WebGL製の縦スクロール弾幕STG。物語・敵・ボス・弾幕をYAMLで定義し、内蔵スタジオでその場で試射できます。キャラクター、物語、描画、音楽はオリジナルです。

**[ブラウザでプレイ](https://liesegang.github.io/astra-test/)**

## 1.1 — 手応えと再挑戦

- 命中光・局所的な火花・撃破リングと、命中／撃破／回収／パワーアップを区別する効果音。通常命中では時間を止めません。
- ボスのスペル突破時だけ、弾幕を消してから標準0.12秒停止。常時の画面揺れはありません。
- ボムは標準0.65秒、追加の弾幕も抑制。消えた弾は光の粒になり、発動地点からリングが広がります。
- 低速移動でアイテム吸引範囲が広がります。一度吸引したアイテムは途中で離れず、通り過ぎて往復もしません。
- パワー1〜4は2／4／6／8方向ショットに対応。25グレイズごとに1,500点。無敵中のグレイズ稼ぎはできません。
- `R`ですぐ再挑戦。ボス中は同じスペルの先頭へ戻り、残機とボムを復元します。既読会話は省略し、選択肢は省略しません。再挑戦とコンティニューは記録対象外です。
- 自機の当たり判定を常時表示。敵の最初の発射には予兆があり、パーティクルは敵弾より下に描画します。
- スマートフォンでは残機・ボム・スコアをプレイ画面直下に表示。サウンドと「演出を控えめに」の設定を端末に保存します。

具体的なパラメータ、設計判断、参照上の留意点は [docs/FEEL.md](docs/FEEL.md) を参照してください。

## 操作

矢印／WASD：移動。Shift：低速・広範囲吸引。Z：射撃・会話送り。X：ボム。Esc／P：一時停止。R：再挑戦。オートショットは初期状態で有効です。

スマートフォンは画面の相対ドラッグで移動し、低速ボタンは長押し、ボムはタップします。サウンドはユーザー操作後に開始し、右上のボタンで無効にできます。

## 開発

Node.js 22以降。ゲームの実行・ビルド・ロジックテストには `npm install` 不要です。

```sh
npm run dev    # http://127.0.0.1:5173
npm test       # Node組み込みテスト
npm run build # dist/index.html / dist/moonlit-stg.html
```

`content/stage.yaml`、`minimal.yaml`、`branching.yaml` が編集対象です。`src/content.mjs` はビルド時に再生成されます。開発サーバーではYAML変更後に再読み込みすると反映されます。YAMLスタジオ内の変更はそのブラウザに保存され、GitHubには自動送信されません。

GitHub Pagesは `main` の更新時に、テスト → 単体HTMLの生成 → Chromium検証 → 配信 → 公開URLの再検証を行います。HTML内にCSS・JavaScript・初期YAMLを内包し、CDNや実行時の圧縮ローダーに依存しません。ブラウザ検証用PlaywrightはCIの一時ディレクトリにのみインストールします。
